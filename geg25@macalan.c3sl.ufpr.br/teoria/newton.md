# Método de Newton para sistemas não lineares

- Ideia é encontrar $F(X)=0$
	- $X$ é um vetor com $N$ incógnitas.
	- $F(X)$ é um vetor com $N$ funções.
	- A cada iteração, calculamos uma aproximação melhor para a solução.

---
## Fórmula central

 $J(X_k)\Delta X_k=-F(X_k)$
 $X_{k+1}=X_k+\Delta X_k$
